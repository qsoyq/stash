# X 脚本测试

所有命令从仓库根目录执行。需要 Node.js 22+、Ruby（标准库 YAML）和 jq；
Playwright 仅作为测试依赖，不进入 Stash 或网页运行时。

```bash
npm ci
npx playwright install chromium webkit
npm run test:x
```

Linux 上首次安装浏览器及系统依赖时，使用
`npx playwright install --with-deps chromium webkit`。测试入口自动启动并关闭只绑定
`127.0.0.1` 的临时 HTTP 服务，不需要手动准备 `/tmp` 中的测试工具。

## 测试范围

- `x-rewrites.cjs`：jq 接口重写、参数绑定、默认值、CSP 和纯滚动方向决策。
- `x-options.html`：默认值、单开关、全部关闭、参数错误输入、各组件隔离。
  通过可控的帧调度验证配置行为，不模拟定时轮询。
- `x-scroll-navigation.html`：真实窗口滚动、反向滚动、顶部/底部边界、可点击性、
  导航容器变化、重挂、页面恢复和页面高度变化。
- `x-double-tap.html`：默认关闭的双击返回、触摸阈值、交互/选区/弹窗保护、严格详情路由、
  SPA 与页面生命周期重置、重复初始化和销毁；仅开启手势时不启动布局更新。
- `x-runtime.html`：真实 MutationObserver / ResizeObserver / requestAnimationFrame，
  时间线节点复用、误隐藏防护、路由切换、重复初始化与销毁、后台暂停，以及
  完整 HTML 响应导航的 DOCTYPE / 文档模式保留。

浏览器测试由 `run-x-browser.cjs` 在 Chromium 和 WebKit 中分别运行 390px、1440px
视口。测试失败或未捕获的页面异常均使进程以非零状态退出；CI 对 PR 和 main 推送
执行同一入口。另以鼠标和启用 `hasTouch` / `isMobile` 的浏览器上下文发送真实输入，
验证双击/双点、保留点赞点击、桌面选词保护以及真实历史只返回一条；窄视口不代替触摸测试。

## 性能回归标准

合成负载为 200 个帖子，每个帖子有 20 个 span。断言针对行为次数而非易波动的耗时：

1. 页面静止 10 秒时，不产生新的查询、布局测量或脚本调度帧。
2. 不安装周期更新定时器，也不对整页执行 `querySelectorAll('span')`。
3. 同一帧内多次改变一个帖子，合并为有限次区域更新，不执行全局文档扫描。
4. 时间线只改变文字高度时，不重新测量横向居中位置。
5. 一连串滚动事件按帧处理，仅显隐状态变化时改写样式，不扫描时间线。

这些标准不能证明 iPhone 的耗电、CPU 或真实 X 的绝对性能提升。

同一 Chromium 合成详情页（200 个帖子 × 20 个 span）静止 10 秒的比较结果：

| 版本 | 全局查询次数 | 全局 span 遍历数量 | 列布局测量次数 |
| --- | ---: | ---: | ---: |
| `951c470`（500ms 轮询） | 420 | 160,000 | 20 |
| 优化版本（变化驱动） | 0 | 0 | 0 |

该比较只衡量页面无变化时的重复工作，包含同一初始 DOM 和默认参数，不能换算成
真实设备的性能百分比。`x-runtime.html` 用相同规模的 DOM 固化优化后零空闲工作约束。

## 真机验收

在支持覆写参数的 Stash 版本中，更新覆写及关联脚本，再重新加载 X：

- iPhone Safari 与主屏幕窗口：首页、搜索、详情、通知/对话页面切换正常。
- 开启上滑隐藏、关闭完整隐藏：初始显示，上滑隐藏，下滑/回顶恢复且可点击。
- 键盘出现、地址栏伸缩、切后台后恢复，不留下永久隐藏的导航祖先。
- 单独关闭各组件开关后保留相应入口；正文中的 `Automated`、`Show probable spam`
  不误隐藏。无法确认结构的文本保留显示。
- 桌面右侧栏有内容时不重叠；右侧栏为空时居中；网站已有 transform 不丢失。
- 在「覆写详情 → 参数」开启「详情页双击返回」（默认关闭）后刷新 X：手机正文/留白快速
  点两次或桌面非交互留白双击，只返回一页；核对时间线滚动位置与原生边缘返回一致。
- 点链接、点赞、回复卡片、图片/视频、输入框，选中文字或打开菜单/弹窗时，不触发返回；
  单击、长按、多指、滚动、跨路由点击不误触；关闭后恢复原有双击行为。
- Safari 和主屏幕窗口检查双击缩放、文字选择及原生左边缘右滑仍可使用。历史无上一页
  时不跳首页；上一页为外站时按浏览器历史离开 X。参数需要 iOS/tvOS 3.7+ 或 macOS 4.4+（Beta）。
